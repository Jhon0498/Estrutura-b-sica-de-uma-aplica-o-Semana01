# Estrutura Básica de uma Aplicação Flask

Este projeto é um exercício acadêmico proposto para a disciplina do professor **Fabio Eduardo Teixeira** no **Instituto Federal de São Paulo (IFSP)**.

Trata-se de uma aplicação web simples desenvolvida em Python utilizando o microframework Flask. O objetivo é demonstrar conceitos fundamentais do Flask, como gerenciamento de rotas, renderização de templates HTML, manipulação de cookies, códigos de status HTTP e redirecionamentos.

---

## Tecnologias Utilizadas

* Python 3.10+
* Flask (Framework Web)

---

```text
├── app.py              # Ponto de entrada da aplicação (inicialização do servidor)

├── templates/
